# A Numerical Investigation of the Fourier-Cosine Method for Option Pricing under the Merton Jump-Diffusion Model

## Overview

Undergraduate mathematics dissertation at Queen Mary University of London.

This project investigates the accuracy and convergence of the Fourier-Cosine (COS) method for option pricing under the Merton jump-diffusion model.

## Tools

- Python for numerical experiments and graphs.
- LaTeX for dissertation writing and mathematical typesetting.
